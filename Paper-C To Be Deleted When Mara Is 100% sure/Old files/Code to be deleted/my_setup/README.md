# My setup: article-style gDMR standalone scripts

This folder contains a fully standalone Bermudan put setup under the generalized Gatheral double mean-reverting (gDMR) model.

The goal is to mirror the article-style workflow used in `paper_setup`, but for the gDMR model from the manuscript:

- `run_monte_carlo_put.py`
  Standalone Longstaff-Schwartz Monte Carlo with direct and low estimators.
- `run_hybrid_put.py`
  Standalone hybrid LSMC-PDE with article-style pathwise pre-surfaces, volatility regression, and an out-of-sample low estimator.
- `compare_put_prices.py`
  Runs both scripts, treats `LSMC direct` as the headline reference, prints relative errors, and saves a professional SVG comparison plot.

## Main improvements

- the LSMC script now uses a richer degree-3 paper-style state basis with payoff powers up to degree `3`
- the default reference run is now a stronger `1000000`-path, `600`-step LSMC setup
- the hybrid script now uses a bounded, compact-support volatility basis on a truncated rectangle `D_v`, following the manuscript
- the hybrid asset grid was tightened around the strike so the direct estimator has better resolution near the exercise boundary
- the comparison script now uses `LSMC direct` as the reference value and reports clear relative errors and standard errors
- the comparison plot now shows point estimates with error bars instead of a simple gap-only bar chart

## Final verified default result

From the current default settings:

- LSMC direct = `6.384535`
- LSMC low = `6.387249`
- Hybrid direct = `6.486941`
- Hybrid low = `6.279662`
- Hybrid direct relative error vs LSMC direct = `1.60%`
- Hybrid low relative error vs LSMC direct = `1.64%`
- Hybrid low relative error vs LSMC low = `1.68%`

So the current default standalone `my_setup` run meets the `2%` direct-error target.
