- Spot `S0 = 100` and maturity `T = 1.0`.
- Bermudan exercise dates: `100`.
- Euler steps: `600`.
- LSMC benchmark seeds: `2026` and `2103`.
- Hybrid seeds: `2026` and `2103`.

- Low tables use the scenario-specific benchmark low reference.
