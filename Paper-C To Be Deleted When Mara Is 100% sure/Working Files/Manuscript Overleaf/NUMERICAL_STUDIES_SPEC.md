# Numerical Studies Specification

This file defines the manuscript-facing purpose, structure, and locked numerical design for the `Numerical Studies` section. It is intended to remove ambiguity before any further drafting, coding, copying, or computation takes place.

## Purpose of the Numerical Studies Section

The numerical section must explain, in the style of a publishable mathematics paper, how the theoretical framework is instantiated in computation and what numerical evidence is obtained for the Hybrid LSMC-PDE method relative to the LSMC benchmark.

The section is not a computational note. It must:

- connect the numerical design to the model and methodology already established in the manuscript,
- justify the chosen experiments,
- report the results in a mathematically disciplined way,
- interpret the numerical behavior with respect to discretization, sample size, stability, and moneyness.

Theoretical sections remain unchanged in the current phase. The numerical section should build on them, not rewrite them.

## Fixed Experimental Setting

The numerical studies are locked to the following calibrated parameter block:

\[
S_0 = 100,\quad v_0 = 0.114,\quad v'_0 = 0.110,\quad r = 0,\quad T = 1,
\]
with
\[
\kappa_1 = 5.5,\quad \kappa_2 = 0.1,\quad \theta = 0.078,\quad \xi_1 = 2.689,\quad \xi_2 = 0.502,
\]
and
\[
\delta_1 = \delta_2 = 0.94,\quad \rho_{12} = -0.982,\quad \rho_{13} = -0.727,\quad \rho_{23} = 0.59.
\]

The Bermudan contract is sampled at `12` exercise dates. Five strike levels are considered:

\[
K \in \{70,80,90,100,110\},
\]

covering deeper OTM through ITM put contracts in the manuscript discussion.

## Benchmark Definition

The manuscript benchmark is fixed and non-negotiable unless the user explicitly changes it later.

The benchmark method is plain LSMC with:

- `1200` Euler steps
- `1,200,000` paths
- `95%` confidence intervals

Benchmark direct prices are the manuscript reference values used in relative-error reporting.

Although low-estimator values may appear in archived source material, the manuscript-facing numerical package is direct-only for the current paper program.

## Mandatory Numerical Study Families

Exactly two study families are mandatory in the manuscript package.

### Fixed paths, varying steps

This study compares LSMC and Hybrid LSMC-PDE at fixed direct-path budgets while the time discretization varies.

The locked design is:

- path budgets: `20,000` and `60,000`
- Euler steps: `24, 48, 72, 96`
- strikes: `70, 80, 90, 100, 110`
- benchmark reference: direct LSMC value from the `1200`-step, `1.2M`-path benchmark

Required manuscript outputs:

- tables of direct prices
- direct standard errors
- confidence-interval information
- direct relative errors
- figure or figures displaying direct relative errors with confidence-interval information
- explanatory text describing what changes as the number of steps varies

### Fixed steps, varying paths

This study compares LSMC and Hybrid LSMC-PDE at fixed time discretizations while the sampling budget varies.

The locked design is:

- fixed Euler steps: `48` and `60`
- path counts: `250, 500, 1000, 2000, 5000, 10000, 20000, 40000, 60000`
- strikes: `70, 80, 90, 100, 110`
- benchmark reference: direct LSMC value from the `1200`-step, `1.2M`-path benchmark

Required manuscript outputs:

- tables of direct prices
- direct standard errors
- confidence-interval information
- direct relative errors
- figure or figures displaying direct relative errors with confidence-interval information
- explanatory text describing the effect of increasing paths at fixed discretization levels

## Reporting Standard

The manuscript reports direct prices only.

This rule applies to both methods in the manuscript narrative:

- benchmark reporting is based on LSMC direct prices
- hybrid reporting is based on Hybrid LSMC-PDE direct prices

Confidence-interval information is mandatory throughout the numerical section.

At minimum, each manuscript-facing table or figure set must make the following available:

- direct price
- direct standard error
- a `95%` confidence-interval quantity or interval bounds
- relative error with respect to the benchmark

## Figure Generation Standard

All manuscript-facing figures must be generated by Python scripts stored in `Manuscript Code`.

- Stored CSV or table inputs may be reused, but the figures must still be regenerated by manuscript-specific Python code.
- Overleaf must consume exported figure assets, not raw plotting code.
- Each figure script must export `.pdf` and `.eps`.
- Each figure must have recorded provenance, including script path, local input files, exported outputs, and output checksums.

## Writing Standard

The numerical section must match the formal register of the theoretical part of the manuscript.

- The prose must remain declarative, technical, and evidence-led.
- The surrounding text of each table or figure must read as publishable mathematical writing.
- Conversational phrases, first-person framing, and manuscript-status language are not allowed.
- Expressions such as `we now turn`, `we next`, `to make this concrete`, `taken together`, and similar commentary-style transitions are not allowed.
- Claims must be restrained and tied to measurable numerical properties such as relative error, confidence-interval width, runtime, and stability across moneyness.

## Interpretation Requirements

The manuscript text accompanying the tables and figures must do more than state numerical values. It must explain:

- why comparatively low path counts and step counts are examined
- why such budgets are relevant for assessing efficiency and practical numerical behavior
- how relative error changes across the discretization grid
- how confidence intervals reflect estimator stability
- how the observed behavior changes across moneyness
- when Hybrid improves substantially over LSMC and when the advantage narrows

These explanations must be written in publication-ready mathematical prose.
